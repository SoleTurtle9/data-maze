# Лабиринт данных

Браузерная головоломка на HTML, CSS и JavaScript с отрисовкой через Canvas. Три уровня, на каждом нужно собрать три фрагмента данных и добраться до выхода. Карты воспроизводимы: фиксированные начальные значения генератора, тупики и циклы с альтернативными маршрутами.

## Запуск

Откройте `index.html` в современном браузере. Установка пакетов и сборка не нужны. Для локального сервера: `python3 -m http.server 8080`, затем откройте http://localhost:8080.

## Управление

- Стрелки клавиатуры или экранные кнопки — перемещение.
- R (в том числе при русской раскладке) или кнопка перезапуска — текущий уровень сначала.
- После победы кнопка «Пройти заново» или R запускает игру с первого уровня.
- Стены и закрытый выход не увеличивают счётчик ходов. Переход на следующий уровень происходит автоматически; счётчик текущего уровня обнуляется. Итог показывает сумму ходов успешно пройденных уровней.

Игрок обозначен зелёным кругом, фрагменты — голубыми ромбами, выход — оранжевыми воротами со знаком × или ↗. Выход закрыт до сбора всех трёх фрагментов. Звукового сопровождения нет.

## Проверка

Требуется Node.js 18 или новее. Команда: `node --test tests/engine.test.cjs`.

Проверяются достижимость всех клеток, всех трёх предметов без прохода через закрытый выход, достижимость выхода, наличие тупиков и циклов, блокировка стен, блокировка выхода, сбор, перезапуск, переходы между уровнями, финальная победа и новая игра. Модель игры отделена от отображения (`engine.js` и `game.js`).

Это учебный прототип. Оценка удобства и баланса на внешних участниках не проводилась.
